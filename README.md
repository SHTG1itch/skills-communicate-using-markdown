# Communicate using Markdown

Learn GitHub Markdown in eleven guided lessons. Practice headings, task lists, code samples, images, and equations, then write a project README with setup, usage, contribution, support, and troubleshooting instructions.

## Start your own exercise

1. [Create your own repository from this template](https://github.com/new?template_owner=SHTG1itch&template_name=skills-communicate-using-markdown). Copy the default branch only, give your repository a name, and select **Create repository**.
1. Open **Actions** in your new repository. Enable GitHub Actions if prompted, and wait for **Step 0** to finish preparing your exercise.
1. Open the new **Exercise: Communicate using Markdown** issue and follow **Step 1**. The exercise bot also adds a link to the issue in your repository's README.
1. Create **start-blog** when Step 1 asks you to. Commit all lesson work to that branch and wait for feedback before starting the next lesson.

This template contains course instructions and checks. Students create `day-1.md` in Step 1 and `project-guide/README.md` in Step 6; completed answers are not included.

## What you will practice

| Steps | Skills |
| --- | --- |
| 1–5 | Headings, task lists, code blocks, accessible images, and LaTeX equations |
| 6–10 | README structure, setup, usage, collaboration, and documentation review |
| 11 | Review and merge a pull request |

No programming experience or local installation is required to begin. Later lessons demonstrate Git commands for readers who want a local copy.
